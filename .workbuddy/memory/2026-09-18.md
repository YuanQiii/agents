## 修复 `pnpm dev` 启动失败：`@iconify/utils` 幽灵依赖

**现象**：`vite --mode test` 启动时报 `ERR_MODULE_NOT_FOUND: Cannot find package '@iconify/utils'`，
并有 `UNRESOLVED_IMPORT` 警告指向 `build/plugins/unocss.ts:5`。

**根因**：
- `build/plugins/unocss.ts` 直接 import `@iconify/utils/lib/loader/node-loaders`（用于 `FileSystemIconLoader` 加载 `src/assets/svg-icon`），
  但根 `package.json` 未声明该包。
- `@iconify/utils@3.1.3` 只是 `@unocss/preset-icons@66.6.8`（范围 `^3.1.0`）的**传递依赖**。
- 项目用 pnpm `nodeLinker: isolated`，且 `node_modules/.modules.yaml` 显示 `publicHoistPattern: []` →
  根 `node_modules` 只含直接依赖，传递依赖只被私有 hoist 到 `node_modules/.pnpm/node_modules`。
  Vite 加载配置时生成的临时文件位于 `node_modules/.vite-temp/`，向上查找拿不到私有 hoist 目录，故解析失败。

**修复**：在根 `package.json` 的 `devDependencies` 中显式声明 `"@iconify/utils": "^3.1.0"`，
然后 `pnpm install`。因版本范围与 preset-icons 一致，lockfile 去重为单一 `@iconify/utils@3.1.3`，无额外下载。

**验证**：
- `node --input-type=module -e "import { FileSystemIconLoader } from '@iconify/utils/lib/loader/node-loaders'"` → OK
- `pnpm dev` → `VITE v8.0.12 test ready in 4256 ms`，无 UNRESOLVED_IMPORT 警告；
  `http://localhost:9527/` 与 `/src/main.ts` 均 HTTP 200。
